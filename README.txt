# TRAVEL AGENT PORTFOLIO & DESTINATION GUIDE
 
## 1. PROJECT OVERVIEW
This repository contains a multi-page web application serving as a professional 
portal for Fredy's Travel Agency.
 
## 2. KEY FEATURES
* Multi-Page Navigation: index.html, colombia.html, and germany.html.
* Interactive UI: CSS @keyframes for "demo" sliding and "flags" rotation.
* Custom Branding: Uses 'Bungee Spice' and 'Momo Signature' Google Fonts.
* Responsive Design: Built using Bootstrap 5.3 and custom Flexbox layouts.
 
## 3. TECHNICAL STACK
* HTML5: Semantic structure.
* CSS3: Advanced animations and Flexbox row/column management.
* SVG: Integrated scalable vector icons for destination surprises.
 
## 4. FILE DIRECTORY STRUCTURE
CSS/style.css      <-- Main layout logic & transitions
HTML/index.html     <-- Travel Agent Profile & Message Form
colombia.html  <-- Colombia Destination Guide
germany.html   <-- Geramany Destination Guide
IMGS/              <-- images

## 5. INSTALLATION & SETUP
1. Clone the repository to your local machine.
2. Ensure all image paths in HTML match the /IMGS/ directory.
3. Open index.html in Chrome, Edge, or Firefox.
